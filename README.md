# Cammy

Make your webcam look good, in real time.

## Run

    pip install -r requirements.txt
    python3 -m cammy --white-balance 1 --denoise --sharpen 0.5

Press `q` or `Esc` to quit. Run `python3 -m cammy --help` for all options.
